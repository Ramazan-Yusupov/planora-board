# Planora Board

Live demo: https://planora-board.vercel.app/

Planora Board — это веб-приложение для управления задачами в стиле канбан-доски. Оно помогает организовать планирование как для личных задач, так и для командной работы.

С помощью доски можно:
- создавать колонки и задачи;
- перемещать карточки между этапами;
- добавлять описания, метки, чек-листы и вложения;
- использовать готовые шаблоны для быстрого старта;
- сохранять данные локально в браузере или в выбранной папке на компьютере;
- экспортировать и резервировать данные.

---

## Кратко

Planora Board представляет собой удобную доску задач, где каждая колонка — это отдельный этап работы, а каждая карточка — конкретная задача.

Карточка задачи может содержать:
- заголовок;
- описание;
- цветные метки;
- чек-листы с подзадачами;
- прикреплённые файлы.

Также есть возможность использовать шаблоны досок — заранее подготовленные наборы колонок и карточек, которые ускоряют старт работы.

Данные сохраняются автоматически в браузере и/или в выбранной локальной папке через File System Access API.

---

## Для тех, кто не понимает, что делает сайт

Если говорить простыми словами, то это цифровая доска, на которой можно:

- собирать задачи по категориям;
- видеть, что уже сделано, что в работе и что осталось;
- быстро менять статус задачи перетаскиванием;
- добавлять подробности, файлы и заметки;
- держать всё в одном месте.

Это похоже на привычную канбан-доску, но в веб-формате.

## Основные возможности

- Канбан-доска с колонками и карточками
- Перетаскивание задач между колонками
- Создание задач с подробным содержимым
- Метки и цветовая классификация
- Чек-листы внутри карточек
- Работа с файлами и вложениями
- Шаблоны досок
- Автосохранение в браузере
- Поддержка локального хранения в папке компьютера
- Экспорт/резервное копирование данных

## Как пользоваться

### 1. Откройте приложение
Перейдите по ссылке:

https://planora-board.vercel.app/

### 2. Создайте новую доску
- Нажмите кнопку "New board"
- Выберите готовый шаблон или создайте пустую доску

### 3. Добавьте колонки и задачи
- Создайте список/колонку
- Добавьте в неё карточки задач
- Перетаскивайте карточки между колонками, чтобы менять их статус

### 4. Откройте карточку
В карточке можно:
- указать описание;
- добавить чек-листы;
- назначить метки;
- прикрепить файлы;
- отслеживать прогресс выполнения

### 5. Сохраняйте данные
Приложение сохраняет данные автоматически.  
Если нужно сделать резервную копию, используйте экспорт/скачивание данных.

### 6. Использование локальной папки
Если вы хотите хранить данные в выбранной папке на компьютере:
- разрешите браузеру доступ к папке;
- используйте режим Folder Workspace;
- данные будут сохраняться в локальной директории.

## Где смотреть код

Ключевые директории проекта:

- `src/app/` — маршруты и страницы
- `src/entities/board/` — доменная логика, модели, утилиты и UI-компоненты
- `src/features/` — реализации конкретных фич
- `src/modules/` — крупные модули приложения
- `src/widgets/` — общие виджеты
- `src/shared/` — общие утилиты и компоненты
- `public/` — статические ресурсы

## Локальная разработка

### Клонирование
```bash
git clone https://github.com/Ramazan-Yusupov/planora-board.git
```

### Установка зависимостей
```bash
npm install
```

### Запуск dev-сервера
```bash
npm run dev
```

После этого откройте приложение в браузере:

```text
http://localhost:3000
```
