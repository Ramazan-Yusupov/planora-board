Planora Board — это веб-приложение для управления задачами в формате канбан-доски. Оно подходит как для личного планирования, так и для командной работы.

Основные возможности:

Канбан-доска с колонками и карточками задач
Перетаскивание карточек между колонками
Создание карточек с:
заголовком
описанием
метками (цветные ярлыки)
чек-листами
вложенными файлами
Создание шаблонов досок для быстрого старта
Автоматическое сохранение данных в браузере
Поддержка локального хранения через Folder Workspace (доступ к папке на компьютере)
Экспорт и резервное копирование данных
Поддержка личного и командного планирования
Проект помогает организовать задачи, разбить их на этапы и держать всё в одном удобном интерфейсе.

Как пользоваться проектом

Открыть приложение
Перейдите по ссылке: https://planora-board.vercel.app/
Создать новую доску
Нажмите кнопку "New board"
Можно выбрать готовый шаблон или создать пустую доску
Добавить списки и задачи
Создайте колонки (списки)
Внутри каждой колонки добавьте карточки задач
Перетаскивайте карточки между колонками, чтобы менять статус задачи
Работать с карточкой
Откройте карточку задачи
Добавьте:
название
описание
метки
чек-листы
файлы
Можно организовать задачу по шагам и отслеживать прогресс
Сохранение данных
Данные сохраняются автоматически в браузере
Чтобы сделать резервную копию, используйте экспорт/скачивание данных
Если вы хотите хранить данные в локальной папке, дайте браузеру доступ к папке через Folder Workspace
Использовать локальную папку
Включите доступ к папке на компьютере
Это позволяет сохранять и читать данные из выбранной директории
Удобно для более стабильного хранения и синхронизации
Краткий сценарий работы
Создали доску
Добавили колонки: "Нужно сделать", "В работе", "Готово"
Добавили задачи в карточки
Установили метки и чек-листы
Перемещаете задачи по этапам по мере выполнения
