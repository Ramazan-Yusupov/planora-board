# Будущая админская зона

Журнал `BoardActivity` остаётся в доменной модели `entities/board`, чтобы локальные действия не терялись. Пользовательская карточка его не отображает.

При этапе аккаунтов здесь появятся:

- route group `app/(admin)/admin`;
- серверная проверка JWT из `ADMIN_JWT_SECRET`;
- server-only access control, без передачи секрета в клиент;
- список действий по проектам и карточкам;
- фильтры по пользователю, проекту и дате.

До появления серверной авторизации админский маршрут намеренно не создан: локальный пароль или JWT в браузере не защитил бы данные.
